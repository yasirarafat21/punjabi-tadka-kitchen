# Punjabi Tadka Kitchen — Assessment Website

A responsive static website concept based on the uploaded Punjabi Tadka Kitchen presentation.

## Included
- `index.html` — complete website structure, page metadata, Restaurant schema markup
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, menu search/filter, demo newsletter validation and enquiry-file download
- `assessment-guide.md` — assessment mapping, analytics plan, launch and YouTube presentation guidance
- `content-calendar.csv` — sample 4-week content plan

## Run locally
Open `index.html` in a modern browser. For a local server, open a terminal in this folder and run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Important before publishing
This is an assessment concept, not a verified live restaurant. Replace placeholder email/contact details and confirm menu descriptions, prices, opening hours, location, allergens and ingredient claims before public use. Images and Google Fonts load from external sources, so internet access is needed for those assets. The forms are demos; they do not send/store personal data. Connect a form/newsletter provider before collecting real customer information.

## Suggested free static hosting
- Netlify: deploy by uploading the extracted folder or connecting a Git repository.
- GitHub Pages: upload the files to a repository and enable Pages in repository settings.
- Cloudflare Pages: connect a Git repository and deploy as a static site.

No build step is required.
